# Muhammad Waqar Ul Mulk — Portfolio

Hey! 👋 This is my personal portfolio website built to showcase who I am, what I can do, and the projects I've shipped.

## What's inside

- **Hero** — A quick intro with animated text and a particle background
- **About** — My background, contact info, and education
- **Skills** — Frontend, backend, AI, and tools I actually use day-to-day
- **Projects** — A filterable grid of my work (web, mobile, AI)
- **Resume** — Download my CV in one click
- **Contact** — Reach me directly through a form powered by Supabase

## Tech stack

| Layer | Tools |
|---|---|
| UI | React 18, TypeScript, Tailwind CSS |
| Animations | Framer Motion, GSAP, Three.js |
| Backend / DB | Supabase |
| Build | Vite |

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) and you're good to go.

## Build for production

```bash
npm run build
npm run preview
```
